이 트랙 전체가 화면 0개다. 기능 자체는 확정(-401 · -402, 중요도 상, Jira ID 부여됨)인데 와이어프레임 14화면 어디에도 원장·검산 화면이 없다. 발표에서 “블록체인 트랙”을 증명하는 화면이 바로 이것이므로 우선도 최상.

D2 결정 — 비로그인은 전 기능 차단(2026-08-27). 원장·검산도 로그인 회원만 접근한다. 명세의 프로토타입·ERD안(“원장·검산은 비로그인 공개 — 제3자 검증이 존재 이유”)은 채택되지 않았다.

남는 사실 하나 — 회원 전용이면 “제3자 검증”은 서비스 안에서만 가능하다. 명세 -402의 “검증에 필요한 데이터 일체를 API로 제공”도 인증이 붙는다. 온체인 머클루트 자체는 체인에 공개돼 있으므로 체인 익스플로러로는 여전히 외부 검증이 가능하고, 서비스가 제공하는 건 그 편의 도구다 — 발표 때 이 구분을 짚으면 D2 결정과 “검증 가능성”이 충돌하지 않는다.
