1 — Conventions

공통 규약

인증 등급 — 공개 비로그인 가능 · JWT 로그인 필요 · 서명 SSAFY WALLET EIP-712 서명 동반. 서명 등급은 토큰이 움직이는 곳 전부다.

인증
Authorization: Bearer <access> — 만료 시 401 + WWW-Authenticate로 재발급 유도. refresh는 HttpOnly Cookie, Redis 회전
페이지네이션
전부 커서 방식 ?cursor=&size= — 예측은 append-only라 오프셋이 흔들릴 일은 없지만 커서가 더 싸다
금액
문자열로 주고받는다 — 토큰이 wei 단위 정수라 JS number 범위를 넘는다
오류 본문
{ code, message, field } — code는 대문자 스네이크 (SIGNER_MISMATCH)
온체인 동반
202 Accepted + 상태 폴링. 201은 오프체인으로 완결되는 경우만
시각
ISO-8601 · Asia/Seoul

4 — Details

주요 엔드포인트 상세

POST/api/predictions서명

서버는 서명에서 주소를 복원해 연동 지갑과 대조한다 — 불일치면 401. 하루 무료 슬롯 3건을 넘기면 2,000 PRT 소각 트랜잭션이 함께 나간다.

Request

{
  "track": "REAL",
  "stockCode": "005930",
  "direction": "UP",
  "targetPrice": 82000,
  "horizon": 20,
  "confidence": 73,
  "note": "외국인 순매수 5일 연속 + 20일선 정배열 전환",
  "signature": "0x8f2c…",   // EIP-712
  "signerAddress": "0x7a3f…c21b"
}

201 Created

{
  "id": 4821,
  "status": "BASE",
  "commitHash": "df1ce27812e47a7c4dbcf89dbe…",
  "anchorStatus": "PENDING",
  "baseDate": "2026-08-25",  // 이 날 종가로 기준가 확정
  "settleDate": "2026-09-22",
  "slotFeeTxHash": null       // 무료 슬롯이면 null
}
HTTPcode조건
400TARGET_DIRECTION_MISMATCH상승 예측의 목표가가 직전 종가 이하
401SIGNER_MISMATCH서명 주소가 연동 지갑과 불일치
402INSUFFICIENT_TOKEN슬롯 초과분 잔액 부족
409SEASON_HORIZON_EXCEEDED남은 시즌보다 예측 기간이 김 (REPLAY)
POST/api/subscriptions서명

즉시 완료되지 않는다. PENDING으로 응답하고 블록 확정 후 인덱서가 ACTIVE로 바꾼다. 70:30 배분은 컨트랙트가 집행 — 응답 값은 사본.

Request

{
  "publisherId": 12,
  "signature": "0x4b1a…"
}

202 Accepted

{
  "id": 903,
  "status": "PENDING",
  "fee": "14900",
  "publisherShare": "10430",  // 70% — 컨트랙트 계산값의 사본
  "txHash": "0x2ef9…",
  "expectedConfirmSec": 6
}
GET/api/ledger/verify/{predictionId}공개

제3자가 플랫폼을 신뢰하지 않고도 검증하도록 필요한 값을 전부 내려준다. 브라우저에서 재계산 가능. 만기 전에는 salt·verdict가 null.

200 OK

{
  "predictionId": 4821,
  "payload": "005930|UP|82000|20",  // 해시 입력 원문
  "salt": "9c4e1f77a2b30d58",
  "commitHash": "df1ce278…",
  "merkleProof": ["a91f…", "77c2…", "0b3e…"],
  "merkleRoot": "5d8a…",
  "anchorTxHash": "0x91bd…",
  "basePrice": 71800,
  "actualClose": 83100,
  "quoteSource": "공공데이터포털 금융위원회_주식시세정보",
  "verdict": "HIT"
}

검증 절차

① hash(payload + salt) == commitHash ?
② merkleProof 로 root 복원
   == anchorTxHash 의 온체인 root ?
③ actualClose == 공공데이터포털 원본 ?
POST/api/wallet/nonce → /api/wallet/linkJWT

지갑 연동은 1회 — 이후 예측 등록마다 EIP-712 서명만 붙는다. nonce는 5분 1회용.

nonce → 200

{ "nonce": "f47ac10b…", "expiresIn": 300 }

link (SSAFY WALLET 서명) → 200

{ "address": "0x7a3f…c21b", "linked": true }
HTTPcode조건
400NONCE_EXPIREDnonce 5분 초과
409WALLET_ALREADY_LINKED주소가 다른 계정에 연동됨
GET/api/rankings?track=REAL&filter=total공개

신뢰도 = (적중률×0.7 + 목표가 정확도×0.3) × 표본 가중치. 13:30 배치에서만 갱신 — Redis 스냅샷 그대로 서빙. REPLAY 실적은 REAL 랭킹에 절대 섞이지 않는다.

200 OK

{
  "track": "REAL", "filter": "total",
  "computedAt": "2026-08-24T13:40:00+09:00",
  "items": [{
    "rank": 1,
    "user": { "id": 7, "handle": "chart_fairy" },
    "score": 84.2, "hitRate": 0.78,
    "avgError": 2.31, "doneCount": 46
  }]
}

Request

{ "tickerId": 3, "side": "BUY", "qty": 10 }

201 Created

{
  "orderId": 771, "status": "FILLED",
  "fillPrice": 45300, "gameDay": 30,
  "cash": "5470000",
  "position": { "qty": 10, "avgPrice": 45300 }
